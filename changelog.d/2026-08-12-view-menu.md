`AppMenuBar.qml` gains a `View` menu with checkable `Action`/`MenuItem` entries bound directly to
`Main.qml`'s existing `columnVisibilitySettings` `Settings` object (reused as-is for the "Scenario
Graph Lines" submenu, built via a `Repeater` over `graphVm.plottableColumns`) and a new
`viewSettings` `Settings` object (category `"view"`) holding the master/section toggles. No VM or
`ISettingsService` involvement — purely QSettings-backed, matching the existing graph-column-visibility
pattern. `DashboardGraphCanvas`, `PlaytimeGraphPanel`, `ControlPanel`, and `SelectionPanel` gain
`visible:` bindings to `viewSettings` in `Main.qml`; submenus are `enabled` only while their master
toggle is on.

`SelectionPanel.qml` gains `recentSectionVisible` and `scenarioBrowserSectionVisible` properties.
The Recent Runs `ToolButton`/`RunListView` are gated by `recentSectionVisible` (ANDed with the
existing `recentExpanded`). The scenario-browser `ScenarioSearchPanel` gets a new `visible` gate, and
`scenarioRuns`' existing `activeScenarioName !== ""` visibility check is ANDed with
`scenarioBrowserSectionVisible` rather than adding a second independent visibility path.

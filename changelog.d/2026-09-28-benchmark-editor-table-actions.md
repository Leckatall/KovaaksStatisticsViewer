The benchmark editor keeps its spanning category and subcategory columns while selected cells tint their scenario rows. A pointer drag moves the selected scenarios to a valid group or Uncategorized, and context menus provide the equivalent group, row, and rank commands.
The footer and headers now host inline creation controls. Adding a scenario creates an unnamed Uncategorized row and opens its name editor; played-scenario suggestions set the selected name and hash in one undoable session edit while retaining the retrospective warning for saved definitions.

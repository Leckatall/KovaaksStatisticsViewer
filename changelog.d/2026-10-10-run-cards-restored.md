Reverts the one-line, zebra-striped table rows introduced for run density (the "Played / Score / Acc / PB" column layout) to the two-line rounded run card, by preference: the card is the app's reusable "this is a clickable run" element, and the table read as static data with a selection style that clashed with the scenario list's.
`ScenarioRunItem.qml` is the card again: a bold `runLabel` title ("<scenario> (<date>)"), then "Score … Acc …" and the PB badge, padding 10, radius 8, `palette.mid` border. The current run keeps a light highlight (`currentRunColor`, the base tinted 8% towards the accent, plus an accent border). Hover now tints the card 7% towards the text colour and brightens its border (pressed: 12%), replacing the old `Qt.lighter(…, 1.2)`, which barely changed a near-black base. Hover is read from a `HoverHandler` (`pointerOver`), which also sets a pointing-hand cursor; `Control.hovered` stays false where the platform disables hover effects. `Accessible.name` summarises the run. Object names `runItem_N`, `runLabel_N`, `runScore_N`, `runAccuracy_N`, `personalBestBadge_N` are as before the table change; `runDate_N`, `runScenario_N` and `runListColumnHeader` are gone, as is the row tooltip and the `scenarioName`/`hits`/`shots` delegate properties (the `scenarioName` model role stays).
`RunListView.qml`: cards are spaced by `cardSpacing` (6); `rowHeight` is now the card pitch (card height + spacing), measured from a hidden `ScenarioRunItem` probe (`runItemProbe`, index -1), and `heightForRows(n)` returns the height of exactly n cards. The expanded Recent section stays bounded to whole cards and keeps its always-visible scroll bar; `SelectionPanel.qml` now sizes it to 2–4 cards within 30% of the column, and the run list's minimum is 2 cards.
Trade-off: the density target from the UI review (SCN-02, at least 8 runs visible at 1280x800 with Recent collapsed) is no longer met; about 7 cards are visible there.
Tests: `tst_RunListView.qml` replaces the density and column tests with card tests (two-line layout, separated cards, a visible hover change) and checks whole-card sizing; `tst_SelectionPanel.qml` checks Recent ends on a whole card and the lists still show at least 2 cards at a 1000x640-like size.

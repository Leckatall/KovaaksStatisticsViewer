`BenchmarkEditorTable.qml`: `thresholdWidth` (was a fixed `property int thresholdWidth: 92`) is now computed: `availableRankWidth` (the table body's width minus the identifying columns and the add-rank slot) split equally over `tierCount`, but never below `rankHeaderMinimumWidth`, so the ranks scroll only when the headers' own widths do not fit. Category, Subcategory and Scenario keep `identityWidths` [130, 120, 200]; the add-rank "+" slot stays after the last rank. The columns cannot be resized by hand, so there is no user-set width to preserve.
`rankHeaderMinimumWidth` measures every rank's header text (bold `FontMetrics`, `rankHeaderText()` shared with the header delegate: "Unnamed" for an empty name, " ⚠" when the rank has issues) plus the header's insets, over all ranks including unloaded columns. It reads the new `BenchmarkTableModel::tierHeaders()` (Q_INVOKABLE, `{name, hasIssues}` per tier in column order) and re-evaluates on model reset, header-data change and column insert/remove.
Header insets tightened so the standard five ranks fit at the default 1180×760 Manager (library pane open: 388px for the ranks, 77px each): swatch margin 5→4px, label left inset 22→20px (`rankHeaderLabelLeftInset`), right inset 4→2px (`rankHeaderLabelRightInset`); "Platinum" needs 76px.
All threshold-view columns stay one width (`hiddenThresholdWidth` = 3 × `thresholdWidth`), which keeps the horizontal scrollbar's estimate exact. Because the hidden identifying columns sit before the viewport, `TableView.forceLayout()` would leave the ranks starting at the old offset after a width change, so `relayoutRankColumns()` (deferred with `Qt.callLater`, and postponed while a cell editor is open) rebuilds the threshold view by re-assigning its model, restores `contentY` and the scrolled rank position, re-lays the header, returns focus, and lets `restoreSessionSelection()` put the selection and current cell back from the manager's anchors.
Tests: `tst_BenchmarkEditorTable::test_rankColumnsShareTheSpareWidthButNeverClipTheirHeaders` (equal shares and no scrollbar when they fit, minimum width and a scrollbar when they do not, no clipped header label, alignment after narrowing, scrolling and widening again), `BenchmarkTableModelHeaders.TierHeadersListEveryRankInColumnOrder`; `tst_BenchmarkTableManagement::test_swatchesAndContextMapping` waits for the width to settle before clicking a rank swatch.

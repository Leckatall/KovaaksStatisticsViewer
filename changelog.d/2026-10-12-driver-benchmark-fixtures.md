The UI driver's synthetic datasets (`rich`, `single`, `short`, `bunched`) now ship checked-in benchmark fixtures from `tools/driver/benchmarks/` instead of a benchmark generated at seed time from `demoBenchmarkSpec()` (removed). The generated one put every threshold at the same multiple of each scenario's PB, so every row sat halfway into Gold, attained and completed rank matched, and every row was a blocker; diagnostic screenshots showed one state.
`driver-demo.json` keeps the id, file name, entry ids and tier ids the tours use, but has fixed round thresholds picked against the rich profile: Clicking is split into Static/Dynamic subcategories and Tracking is flat, with rows above Platinum, low Bronze (recent average in Iron, the only blocker), Gold at 90% to Platinum, Iron (recent below it) and played-but-below-Iron. Attained Bronze, none completed, next Silver.
`driver-many-tiers.json` is a 12-tier alternative (Iron…Celestial) with every row ranked, so the completed-rank tick shows and the tier header overflows at 960x700.
The gallery's rich profile gains a fifth scenario, `Air CELESTIAL No UFO Easy Slowed` (hash `gallery-celestial`, a real Viscose benchmark name, new `gallery-celestial` run shape, 7 runs on days 13–25 at 20:00, seeds after the existing runs so the other scenarios and the latest run are unchanged); the DAT-03 golden in `DriverSpecTest.BuiltInDatasetsAreUnchanged` is updated deliberately. `gallery-celestial` is also accepted as a profile-spec `shape`.
`seedSessionData` takes the fixture directory (`KSV_DRIVER_BENCHMARKS_DIR`, a public compile definition of `ksv_driver_core`) and copies `*.json` from it, making the copies writable; `ksv_driver` writes `benchmarks/lastSelectedId=driver-demo` for these datasets on a fresh session, since with two selectable benchmarks the app auto-selects none (`--setting` still overrides it).
`DriverBenchmarkFixtureTest` seeds sessions exactly as the driver does and evaluates both fixtures, asserting each row's tier, recent-average tier, group ranks, attained/completed/next tier and blockers, so a change to the run generator that drifts the fixtures fails loudly.
Tours: `full` and `unreachable` add the relocation-prompt subcategory to Tracking (Clicking no longer holds scenarios directly); `full` and `smoke` add shots of the 12-tier benchmark.

The acceptance criteria in `docs/features/benchmarks/requirements.md` were audited against the code and tests; every criterion with full coverage is now checked off. The invalid-file criterion stays unchecked: `ProblemBenchmark` carries only `Invalid`/`Unsupported`, so the manager lists a broken file as "Invalid" without saying why (malformed JSON, dangling tier reference, duplicate id, unknown schema version).
New tests close the gaps that the audit found:
`tests/domain/benchmark_evaluator_test.cpp`: `BenchmarkAttainment.AScoreEqualToAThresholdAttainsThatTier` (equality qualifies, just below does not); `BenchmarkAverageRank.WeighsEveryScenarioEquallyAndCountsAnUnplayedOneAsZero` (checks the current average, not only the history); `BenchmarkAverageRank.AScoreAboveTheTopTierCountsAsTheTopTierWithoutCappingThePersonalBest`; `BenchmarkRecentAverage.UsesExactlyTheLatestFiveRunsAndNeverChangesAttainment` (an early silver PB followed by six sub-bronze runs keeps silver attainment and a 2.5 normalized rank while the recent average is the mean of the last five); `BenchmarkRank.RecategorizingChangesAttainmentButNotTheAverageRank` (the same runs read with two uncategorized scenarios vs. one interchangeable category: attained bronze vs. gold, completed bronze both times, identical average and history).
`tests/domain/benchmark_validation_test.cpp`: `EmptySubcategoryIsIncomplete` (targets the empty subcategory's id) and `AnEmptyUncategorizedSectionLeavesAFullyCategorizedBenchmarkTrackable`. The older `EmptyUserCategoryIsIncompleteButEmptyUncategorizedIsNot` never actually emptied Uncategorized.
`tests/domain/benchmark_editor_test.cpp`: `ManualBenchmarkHoldsKnownAndUnplayedScenariosTogether`.
`tests/qt_data/benchmark_store_test.cpp`: `IncompleteWorkRoundTripsExactlyAndKeepsItsIssues` (partial thresholds, colours, a mapped hash in a subcategory and an empty category all survive write + scan, compared with `operator==`, and the completeness result matches `validateBenchmark`); `UnsupportedFileIsNeverRewritten` (repeated scans and a create attempt leave the newer-version bytes untouched).
`tests/integration/benchmark_composition_test.cpp`: `AuthoringRoundTripImportsSavesReopensAndDeletes` now also compares the full imported order with `PlaylistReader`, asserts no tiers or categories are invented, and asserts that the saved import loads as Incomplete. New `RefreshLoadsACopiedFileAndClearsAFixedProblemWithoutRestarting` (a copied-in file and a repaired malformed file both load on `refresh()`, and the copied benchmark becomes trackable) and `UnsupportedFileIsReportedAndNeverRewrittenByAutomaticMapping` (a schemaVersion-99 file holding an auto-mappable scenario name stays byte-identical after startup resolution, is reported Unsupported, and tracks as Unavailable).

`GraphConfiguration` (`src/app/contracts/graph_configuration.h`, `ksv_contracts`) — Qt-free value snapshot of per-graph preferences keyed by `GraphKey` (`run`, `dailyPlaytime`, `scenarioHistory`, `benchmarkRank`, `benchmarkPlaytime`) plus the Graph Lines `RunSeriesDocument` and the run graph's Y-axis-label series. Ranges are a variant of all history, recent days, inclusive `year_month_day` custom dates and latest runs (scenario history only); appearance is a connection mode plus a separately kept line-mode marker preference; series colour/width overrides and numeric axis policies (fit visible, start at zero, fixed bounds) are keyed by stable local series/axis keys from `graphDescriptor()`.
Defaults reproduce the existing look: all history, three-day playtime averaging, smooth lines with markers only on scenario history, the existing series colours at SeriesPainter's width 3, fit-to-data score/accuracy axes and zero-based counts/playtime axes, no generic fitting for the rank or run graph.
`validateGraphPreferences()` / `validateGraphConfiguration()` return issues keyed by graph, group (`dataRange`, `axes`, `seriesStyle`, `graphLines`), series/axis key and field, rejecting inapplicable or missing fields, invalid or reversed dates outside 1970-01-01..9999-12-31, non-positive or over-limit day/run/window counts, non-finite or out-of-range widths and bounds, and fixed bounds whose minimum is not below the maximum; the Graph Lines document is checked for the same allocator and axis-reference rules its codec enforced.
`GraphConfigurationPersistence` (`src/qt_data/`) implements the new `data::IGraphConfigurationPersistence` port over `ISettingsService`: schema version 4 of the `graph/seriesConfigV1` JSON adds `graphs` and `runAxisLabelSeriesId` beside the version-3 series section; versions 1-3 migrate as before and missing graph sections take defaults. Each section decodes on its own, so an invalid graph section or series section quarantines the raw document and defaults only that section; unparseable or unsupported documents follow the existing quarantine-and-seed path. Custom dates are stored as ISO `YYYY-MM-DD` strings. Saving submits the document without status checks or read-back.
The run graph's axis-label choice that `VisualSettingsManager.qml` stored under `graphAxis/seriesId` is imported through the new `ISettingsService::getLegacyRunAxisLabelSeriesId()` whenever the document carries no choice of its own.
The series JSON codec moved from `SeriesConfigStore` into `series_config_codec` and now validates through `validateRunSeriesDocument()`; `SeriesConfigStore` reads the series section of a version-4 document and shares `sameSeriesConfigs()` / `sameAxisConfigs()` from the contracts. The new persistence adapter is not yet wired into `App`.

Test-suite review: removed tests that earned nothing and rewrote tests coupled to the shipped defaults. The rubric, per-slice evidence and the approved list are in `.plans/2026-10-21/test-suite-review/` (`removals.md` names every deleted test with its reason).

Removed 118 tests, by rubric category: 81 duplicated another test (the partner test and the production change both fail on are named per entry), 20 restated a constant/default/table, 13 could not fail, 2 asserted only what a fake was configured to return, 2 tested the framework rather than project code. By layer: domain 8, qt_data 3, app 30, integration 13, ui C++ 21, QML 43. One whole file went: `tests/domain/benchmark_projection_shape_test.cpp`.
The default-table tests (`SeriesConfigTest.DefaultLinesMatchTheApprovedTable`, `DefaultAxesAreScoreAndAccuracyWithFixedIds`, `GraphConfigurationDefaults.*`, `GraphPresentation.DefaultsReproduce…`) are replaced by two invariant tests that survive default changes: `SeriesConfigTest.DefaultRunSeriesDocumentIsValid` (valid document, unique ids, dense positions, every `yAxisId` names an axis, allocators computed as max id + 1) and `GraphConfigurationDefaults.DefaultGraphConfigurationIsValid` (every key's preferences valid and equal to `defaultGraphPreferences`, every descriptor series' `axisKey` in its graph's axes).

Rewrote about 146 tests (app/lower layers 49, ui C++ ~75, integration 20, QML 2) so they no longer depend on the shipped defaults they are not about: expectations come from `default*()` / `k*` constants instead of copied literals, ids and counts are derived from the configuration under test (fixture helpers in `settings_vm_test.cpp` and `run_series_authority_test.cpp`, a local `smallLineup()` in `series_config_test.cpp`, a `SharedAxisVm` fake in `graph_canvas_geometry_test.cpp`), and "edits" that wrote the default value now write a non-default one.
About a dozen of those rewrites fix tests that could not fail on the regression their name describes: no-op edits in `graph_draft_test.cpp`, a window "change" to the default in `playtime_graph_vm_test.cpp` and `dashboard_ui_test.cpp`, a stored width equal to the painter width in `graph_vm_test.cpp`, a marker check on a pixel the line also covers in `series_painter_test.cpp`, an `integral` check on a range that is always whole in `axis_policy_test.cpp`.

Follow-ups, not changed here: the shared fakes (`tests/support/fake_graph_configuration_use_case.h`, `fake_graph_configuration_persistence.h` and several file-local fakes) start from `defaultGraphConfiguration()`, the root of most remaining default coupling; order-dependent shared fixtures (`CompositionRootTest`, several QML test cases); `run_series_authority_test.cpp` is a persistence test in the app layer; measurement harnesses that assert no timings run in the CTest gate; and the coverage gaps and weak assertions listed in `removals.md`.

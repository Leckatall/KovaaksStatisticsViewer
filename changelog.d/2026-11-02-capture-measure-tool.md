`ksv_capture_measure` — developer tool behind `KSV_BUILD_CAPTURE_MEASURE` (default OFF), built and deployed by `scripts/package-release.ps1 -CaptureMeasure` into `build-measure`. Records per-case render, snapshot, PNG save, peak memory and GUI-thread gap figures to CSV for the capture limits gate.

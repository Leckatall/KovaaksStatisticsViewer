The Architecture Description now cites ADRs 0008, 0009 and 0010 in place of the superseded ADRs 0005 and 0006.
The root's Owned data section states the ADR 0010 ownership rule, and the decision list replaces the 0005 and 0006 entries with 0008-0010. The benchmarks view drops its three differences from ADR 0005, which no ADR now states, and the benchmark-editing view ties the edit lease to ADR 0008. The graph-configuration and run-history-data views link ADRs 0009 and 0010.
Two departures from ADR 0010 are recorded as debt: graph-configuration persistence has no failure channel, so memory can move ahead of storage, and the QML-owned `Settings` groups persist state with no data-layer authority. The documented version is unchanged, because this was an ADR-scoped update, not a full reconciliation.

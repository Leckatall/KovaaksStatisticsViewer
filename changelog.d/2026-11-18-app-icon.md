`resources/app-icon/ksv.rc` embeds `app-icon.ico` as `IDI_ICON1` and is compiled into the `ksv` target; Qt's Windows platform plugin loads that resource as every window's default icon, so no `setWindowIcon` call is needed.
`app-icon.svg` is the master. `scripts/make_app_icon.py` renders it at each of 16/20/24/30/32/36/40/48/64/96/256 px (each size rendered directly, not downscaled) into the committed `.ico`, so the build stays Python-free.
